# ヤギの絵

ruminy に出るヤギの絵の一覧と、生成 AI に描かせるときの指示文。
どこに何を出すか、なぜそうしたかは [design.md の「マスコット」](design.md#マスコット) を参照。

絵は `public/mascot/` に置く（透過 PNG の正方形）。

## 絵の決まり

- **濃紺（#1D2B3F）のインクの線画だけ**で描く。塗りや影、ほかの色は使わない（線の内側は白）
- 背景は透明。文字と枠は入れない
- **片方の頬（向かって右）が、噛んでいるものでふくらんでいる。** 反芻（もぐもぐ）がこのヤギの特徴で、404 以外のすべての絵で守る
- 噛んでいるのは本の欠片。本が出る絵では、**本の右上の角が半円形にかじり取られている**（歯形）
- ヤギは本を大事そうに扱う。本を壊しているようには見せない

## 一覧

| ファイル | 大きさ | 出る場所 | 様子 |
|---|---|---|---|
| `face.png` | 小（16〜40px） | ヘッダー、ファビコン、ホーム画面のアイコン | 正面の顔だけ。頬のふくらみを大きめに |
| `login.png` | 大 | ログイン | 座って開いた本を抱え、半目で少し上を見ながら、考え込むようにもぐもぐ噛んでいる |
| `offer.png` | 大 | ノートの空欄（ひな形を読み込む前） | 噛みながら、1枚の紙（プリント）をこちらへ差し出している |
| `not-found.png` | 大 | 404 | 本のページを丸ごと口に入れてしまい、両頬がぱんぱんで気まずそう |
| `rest.png` | 大 | 何もないとき（作品なし、未公開など） | 寝そべって目を閉じ、のんびり反芻している |

## 生成の状況

すべて生成済みの透過 PNG。`face.png`・`login.png`・`offer.png`・`not-found.png` は 1254×1254、`rest.png` は寝そべっているため横長の 1536×1024。
`Mascot` コンポーネントは `size` を高さとして扱い、幅は縦横比から決める（`rest` は高さ 96px なら幅 144px）。
一覧にない `mascot.png`（立っている全身）は、共通の前置きだけで生成した汎用の絵。`rest.png` ができるまで代わりに使っていた。使える場面があれば使う。

`face.png` は画像の中で顔が小さく、余白が多い。そのまま 16px・32px に縮めると潰れるため、
アイコンとして使うときは余白を切り詰めて顔を画像いっぱいに広げたものを生成する（実装時に生成の仕組みを作る）。

## 描く順番

1. `face.png` を描く。小さく表示しても形が分かるかを、16px・32px・40px に縮小して確かめる
2. 気に入った `face.png` を参照画像として添えて、残りの 4 枚を描く。顔つきと線の太さがそろう

## 指示文

**共通の前置き**（どの絵も、これに続けて場面ごとの指示を書く）

```
ヤギのキャラクターを描いてください。

・濃紺（#1D2B3F）のインクだけで描いた線画。ノートの余白にペンで描いた落書きのような、手描きの揺らぎのある線
・塗り、影、グラデーション、ほかの色は使わない。線の内側は白
・背景は透明。文字や枠は入れない
・正方形の画像で、キャラクターを中央に、上下左右に少し余白を残して配置する
・リアルにしすぎず、シンプルで親しみやすい絵柄
・短い角が2本、横に垂れた耳、小さなあごひげ
・反芻しているヤギで、向かって右の頬だけが、噛んでいるものでぷっくりとふくらんでいる。あごを少し横にずらして、もぐもぐ噛んでいる
```

**face.png**

```
正面を向いた顔だけを描いてください。体は描かないでください。
小さく表示しても形が分かるよう、線はやや太めにして、描き込みを減らしてください。
向かって右の頬のふくらみは、はっきり大きく描いてください。
```

**login.png**（`face.png` を参照画像として添える）

```
添付画像のヤギと同じ顔つき・同じ線で、全身を描いてください。
座って、両方の前足で開いた本を大事そうに抱えています。
半目で少し上を見ながら、考え込むようにもぐもぐ噛んでいます。
本の右上の角は、半円形にかじり取られています（歯形）。頬のふくらみは、その本の欠片です。
```

**offer.png**（`face.png` を参照画像として添える）

```
添付画像のヤギと同じ顔つき・同じ線で、全身を描いてください。
立って、1枚の紙（罫線が数本引かれたプリント）を、前足でこちらへ差し出しています。
もぐもぐ噛みながら、おだやかな表情です。
```

**not-found.png**（`face.png` を参照画像として添える）

```
添付画像のヤギと同じ顔つき・同じ線で、全身を描いてください。
本のページを丸ごと口に入れてしまい、両方の頬がぱんぱんにふくらんでいます。
口の端から紙の端がはみ出しています。
気まずそうに、目をそらしています。そばに、ページが減った本が置いてあります。
```

**rest.png**（`face.png` を参照画像として添える）

```
添付画像のヤギと同じ顔つき・同じ線で、全身を描いてください。
足を折りたたんで寝そべり、目を閉じて、のんびりもぐもぐ反芻しています。
そばに、右上の角が半円形にかじり取られた本が閉じて置いてあります。
```
